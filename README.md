# Shawon AI 💙

Private real-time messenger for two people.

## Features

- Real-time messaging (PeerJS) – messages appear instantly
- No login required
- Beautiful futuristic glass UI
- Shawon side → messages persist forever (localStorage)
- Partner side → messages clear when browser is closed (sessionStorage)
- Chrome notifications
- Free AI replies when away
- Chat export
- Shared room code

## How to use

1. Both open the same deployed link
2. Enter the **same Shared Code**
3. One selects **I am Shawon**, the other **I am Partner**
4. Wait until status shows **Online**
5. Start chatting – messages appear instantly on both sides

## Deploy on Vercel + GitHub

1. Create a new GitHub repository
2. Upload all files from this folder
3. Go to [vercel.com](https://vercel.com) → New Project → Import the repo
4. Deploy (zero config needed)
5. Share the `*.vercel.app` link

## Notes

- Open Shawon side first, then Partner side for best connection
- PeerJS free cloud is used – usually connects in 1-3 seconds
- Messages can be in any language (Bangla is fine)
